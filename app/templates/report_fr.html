Méthodologie et limites

Cet audit combine : (1) une analyse technique 100 % automatisée de votre page d'accueil et de votre robots.txt ; (2) {{ n_queries or 15 }} requêtes réelles posées à {{ engines_summary or "Perplexity Sonar" }}{% if multi_engines %} (soit {{ citations_total }} mesures requête × moteur){% endif %} dans la langue de votre site, générées à partir de votre secteur analysé (« {{ keyword }} ») ; (3) une comparaison automatisée avec les pages concurrentes citées par l'IA. Les citations dans les réponses d'IA varient dans le temps et selon les utilisateurs : ce rapport est une photographie à la date de génération, pas une garantie de citations futures.
